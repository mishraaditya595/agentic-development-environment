# feature-delivery

Portable Agent Skills package for the Agentic Development Environment.

**Use when:** Coordinate a complete, reviewable software feature from repository discovery and implementation planning through coding, testing, independent review and PR handoff. Use when asked to build or deliver a feature end to end. Keep trivial work proportionate and never automatically merge or deploy.

Install from the public repository:

    npx skills add mishraaditya595/agentic-development-environment --skill feature-delivery

The entrypoint is [SKILL.md](SKILL.md). [Evaluation prompts](evals/representative-prompts.md) are examples for manual routing and quality assessments. The package is independently usable without installing the full ADE environment.
