# Investigation checklist

- [ ] Symptom, impact, scope, and reproduction are recorded.
- [ ] Error output and recent changes were read completely.
- [ ] Relevant repository commands and instructions were found.
- [ ] Data flow and component boundaries were traced.
- [ ] A working comparison was inspected.
- [ ] One hypothesis was tested in isolation.
- [ ] A regression check exists or its absence is explained.
- [ ] Code and environment failures are separated.
