# plan-creator

Portable Agent Skills package for the Agentic Development Environment.

**Use when:** Write an implementation-ready, repository-grounded software development plan with scoped tasks, dependencies, acceptance criteria, verification and risks. Use when someone asks to plan a feature, architecture change, migration, or milestone without yet implementing it. Do not change production code.

Install from the public repository:

    npx skills add mishraaditya595/agentic-development-environment --skill plan-creator

The entrypoint is [SKILL.md](SKILL.md). [Evaluation prompts](evals/representative-prompts.md) are examples for manual routing and quality assessments. The package is independently usable without installing the full ADE environment.
