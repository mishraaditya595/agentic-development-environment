# plan-implementer

Portable Agent Skills package for the Agentic Development Environment.

**Use when:** Implement an already agreed software plan or scoped task, maintaining traceability to acceptance criteria and producing verified test evidence. Use when asked to execute a plan, milestone, or task list; do not use for plan-only requests or independent code review.

Install from the public repository:

    npx skills add mishraaditya595/agentic-development-environment --skill plan-implementer

The entrypoint is [SKILL.md](SKILL.md). [Evaluation prompts](evals/representative-prompts.md) are examples for manual routing and quality assessments. The package is independently usable without installing the full ADE environment.
