# repo-onboarding

Portable Agent Skills package for the Agentic Development Environment.

**Use when:** Inspect an unfamiliar software repository and produce a grounded architecture, tooling, conventions, and verification map before planning, debugging, reviewing, or modifying code. Use for repository onboarding, first-time feature work, or when the relevant code ownership is unclear. Do not use to implement features.

Install from the public repository:

    npx skills add mishraaditya595/agentic-development-environment --skill repo-onboarding

The entrypoint is [SKILL.md](SKILL.md). [Evaluation prompts](evals/representative-prompts.md) are examples for manual routing and quality assessments. The package is independently usable without installing the full ADE environment.
