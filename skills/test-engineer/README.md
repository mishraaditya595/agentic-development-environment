# test-engineer

Portable Agent Skills package for the Agentic Development Environment.

**Use when:** Design, implement, and evaluate meaningful software tests for changed behavior, regressions, error handling and data integrity. Use when asked to add test coverage, reproduce a bug with tests, or assess assertions. Do not substitute test count or mocks for behavioral evidence.

Install from the public repository:

    npx skills add mishraaditya595/agentic-development-environment --skill test-engineer

The entrypoint is [SKILL.md](SKILL.md). [Evaluation prompts](evals/representative-prompts.md) are examples for manual routing and quality assessments. The package is independently usable without installing the full ADE environment.
