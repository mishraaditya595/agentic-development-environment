# ADE harness operations — implementation notes

This branch adds local session checkpoints, multi-repository check aggregation and fixture-based sensor proof. Source code is in harness/session.py, harness/workspace.py and harness/sensors.py. All operations remain opt-in; the CLI will not automatically start long-running processes or modify other repositories.

Limitations: session state is a local append-only journal, not a cloud synchronization system; workspace checks execute only developer-configured commands, not automatically derived API contract checks; sensor proof validates known fixtures, not the complete integration of each sensor into CI or a test runner. Native hooks and a distributed agent router are deliberately absent.
