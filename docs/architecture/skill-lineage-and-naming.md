# Skill lineage and naming

This catalog uses outside projects as research input, not as source text. Published skills must have original names, descriptions, examples, and workflow language. A name describes the behavior a user can invoke and becomes a stable public interface after publication.

New packages inspired by development-methodology research must add app-native improvements: evidence checkpoints, proportional process, explicit uncertainty, repository-aware exceptions, and authorization-aware side effects. Each package includes at least one positive trigger, one boundary case, and one difficult scenario in its evals.

The current planned names are `root-cause-investigation`, `proof-before-done`, `behavior-first-engineering`, `intent-to-implementation`, `review-feedback-triage`, `coordinated-agent-delivery`, and `branch-closeout`.
