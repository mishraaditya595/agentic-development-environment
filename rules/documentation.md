# Documentation accuracy

- When behavior, schema, environment requirements, commands or architecture change, identify affected docs and update them within scope.
- Verify commands and paths against the repository rather than assuming they work.
- Clearly label planned functionality, examples, and unverified behavior; avoid presenting proposals as shipped features.
- Keep READMEs, agent instructions, examples and reference docs mutually consistent.
- Do not rewrite existing contributors' documentation unnecessarily or remove historical research.
